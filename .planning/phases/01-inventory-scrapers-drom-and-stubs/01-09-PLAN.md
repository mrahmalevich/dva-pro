<objective>
Phase 1 plan 09 — Live drom smoke run gate (manual / human-in-the-loop).

This is the production gate that verifies fixture-driven correctness against the real drom.ru DOM. It is INTENTIONALLY NOT autonomous — it requires:
- Network connectivity to drom.ru from a residential IP (founder home preferred over cloud VM per RESEARCH Risk 2 mitigation).
- Multi-minute-to-hours wall-clock time (1 brand × ~10 models × ~4 generations × 10 s/req ≈ 7–10 minutes for a small brand like LADA; ~1 hour for BMW).
- A human to read `report.json` and decide whether to proceed to a full backfill OR fix parsers and re-smoke.

Two checkpoints:
1. **Smoke run on a single brand (gate-blocking)** — verifies parsers + orchestrator + image pipeline + cursor + symlink + brand-aliases all work end-to-end against live drom. After green, Phase 1 is COMPLETE.
2. **Full backfill kickoff (informational)** — kicked off in the background; runs for 1–2 weeks; Phase 2 / Phase 3 do NOT wait for this. The smoke run is sufficient for Phase 1 completion.

Output: 0 source files. Live drom artifacts under `data/scraped/drom/<run_id>/` (all gitignored). Human decides next step from `report.json`.
</objective>


## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator's machine → drom.ru | Live HTTP egress; rate limits enforced by D-14 |
| Operator command → orchestrator | Untrusted brand whitelist via env var (the only externally configurable knob) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | DoS | Operator runs `pnpm scrape:drom` on a cloud VM and gets the dev IP rate-limited | mitigate | Plan 08's README documents "run from a residential IP (founder home connection)" — this plan's Task 1 reiterates. If blocked, the orchestrator exits 3 cleanly; resume after 24h from a different IP. |
| T-09-02 | Tampering | DROM_BRAND_WHITELIST passed via shell injection | accept | The env var is split on `,` and lower-cased; non-matching values silently filtered. No shell exec; no code injection surface. |
| T-09-03 | Information Disclosure | drom records inadvertently include user-tracking IDs | accept | drom catalog pages are public, no PII; the orchestrator records only the URL + parsed fields per D-10 schema. |
| T-09-04 | Repudiation | Operator runs Task 2 backfill, machine sleeps mid-run, orchestrator hangs | mitigate | The got `timeout: { request: 30_000 }` (plan 03) bounds individual fetches. If the OS suspends the process, the resumable `.cursor.json` (plan 06) means the next invocation continues from the last brand boundary. |
| T-09-05 | DoS | Full backfill fills the disk | accept | Plan 08's README documents the manual prune command. Disk capacity is operator's responsibility. |
</threat_model>
