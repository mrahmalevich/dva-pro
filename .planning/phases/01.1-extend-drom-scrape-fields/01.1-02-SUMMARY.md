# Phase 01.1 Plan 02: Complectation Zod Schema + ModelRecord Extension Summary

**One-liner:** Complectation zod schema with 6 named groups (D-06 leaf counts: 7/2/6/9/6/2), optional _extraction_errors annotation, wired into ModelRecord with backward-compat .default([]) and ReportSummary.field_coverage optional.

## What Was Built

Extended `server/scrapers/shared/types.ts` (was 1972 bytes / 58 lines; now 4627 bytes / 135 lines) with:

1. Six named group sub-schemas at the top of the file, each with exact D-06 leaf counts:
   - `Identity` — 7 leaves (name, period_from, period_to, tier enum, engine_code, frame_code, source_url)
   - `Pricing` — 2 leaves (price_new_rub, price_used_from_rub)
   - `Drivetrain` — 6 leaves (engine_cc, engine_hp, engine_fuel enum, drive, transmission_type enum, transmission_gears)
   - `Dimensions` — 9 leaves (length_mm, width_mm, height_mm, wheelbase_mm, clearance_mm, trunk_min_l, trunk_max_l, curb_weight_kg, gross_weight_kg)
   - `Comfort` — 6 leaves (seats, doors, fuel_consumption_city_l, fuel_consumption_highway_l, fuel_consumption_combined_l, tank_l)
   - `Tires` — 2 leaves (tires_front, tires_rear)

2. `Complectation` top-level schema composed of all 6 groups + optional `_extraction_errors: [{group, message}][]`

3. Re-export line: `export { Identity, Pricing, Drivetrain, Dimensions, Comfort, Tires }` for Plan 05 extractor unit tests

4. `complectations: z.array(Complectation).default([])` added as last field of `ModelRecord` — backward-compat for `inheritFromPrevCurrent` which reads legacy `models.json` without complectations

5. `FieldCoverage` type alias with 6 numeric group coverage fields

6. `field_coverage?: FieldCoverage` added to `ReportSummary` for Plan 07 orchestrator emission

Created `server/tests/complectation-schema.test.ts` with 7 tests (5 in Complectation describe + 2 in ModelRecord describe):
- R-2: all-null record parses successfully
- R-3: missing group key throws
- R-3: D-06 leaf counts (7/2/6/9/6/2)
- _extraction_errors annotation accepted
- malformed _extraction_errors rejected
- legacy ModelRecord without complectations gets default []
- ModelRecord with one complectation round-trips
