### `server/scrapers/drom/parse-complectation-page.ts` (parser, transform)

**Analog:** `server/scrapers/drom/parse-generation-page.ts`

**KEY INVERSION (RESEARCH §Pattern 1, SPEC R-6):** The analog throws-loudly on zod failure (Pitfall 1 DOM-regression detector, line 256-258); the new parser is **fail-soft**: every `extract<Group>()` is wrapped in `try/catch` returning `null`, and the final `safeParse()` (not `.parse()`) emits an all-null record on schema mismatch. export function parseComplectationPage(html: string, ctx: ComplectationPageContext): Complectation {
  const $ = cheerio.load(html);
  const errors: { group: string; message: string }[] = [];

  const dimensions = safeExtract(() => extractDimensions($), 'dimensions', errors);
  const comfort    = safeExtract(() => extractComfort($),    'comfort',    errors);
  const tires      = safeExtract(() => extractTires($),      'tires',      errors);
  const drivetrain = safeExtract(() => extractDrivetrain($, ctx), 'drivetrain', errors);
  // identity + pricing come from ctx.trimRow (parent gen-page); not from this HTML
  const identity   = identityFromCtx(ctx);
  const pricing    = pricingFromCtx(ctx);

  const candidate: Complectation = {
    identity, pricing, drivetrain, dimensions, comfort, tires,
    _extraction_errors: errors.length > 0 ? errors : undefined,
  };
  // safeParse, NOT .parse - never throw at this boundary (SPEC R-6)
  const parsed = ComplectationSchema.safeParse(candidate);
  if (!parsed.success) {
    return allNullComplectation(ctx, [
      ...errors,
      { group: 'schema', message: parsed.error.message },
    ]);
  }
  return parsed.data;
}

**Per-section extractor pattern** (RESEARCH §Code Examples lines 449-538 - drop in verbatim):
```typescript
function valueByLabel($: cheerio.CheerioAPI, label: string): string | null {
  const labelCell = $('td, th, span, dt')
    .filter((_, el) => $(el).text().trim() === label)
    .first();
  if (labelCell.length === 0) return null;
  const value =
    labelCell.next('td, dd, span').text().trim() ||
    labelCell.parent().next().text().trim();
  return value || null;
}

function numFromLabel($: cheerio.CheerioAPI, label: string): number | null {
  const raw = valueByLabel($, label);
  if (!raw) return null;
  const m = raw.match(/(-?\d+(?:[.,]\d+)?)/);
  if (!m) return null;
  const n = Number(m[1].replace(',', '.'));
  return Number.isFinite(n) ? n : null;
}
```

**Cheerio call shape carried from analog** (lines 140-163 of `parse-generation-page.ts`):
- Use `$('selector').each((_, el) => { ... })` for collection iteration (line 145, 212).
- Use `$(el).text().trim()` for cell value extraction.
- Use `cheerio.load(html)` once at top of function (line 184); pass `$` down.
- **DO NOT** use class-based selectors like `.r6hmq22` for new per-comp leaves - per RESEARCH Pitfall 2 / "Don't Hand-Roll" line 324, prefer label-text scans. The analog's class-based selectors are kept only because they were observationally stable; new per-comp selectors must use the `valueByLabel()` shape.

**Class-with-counter pattern** (analog lines 43-69 - exact shape):
```typescript
export class ProbeDownLimiter {
  private delayMs = CEIL_MS;
  private consecutiveOk = 0;

  getDelayMs(): number {
    return this.delayMs;
  }

  /** Feed each request's FINAL post-retry status (Pitfall 5: not per-attempt). */
  onResponse(statusCode: number): void {
    if (statusCode === 429 || (statusCode >= 500 && statusCode < 600)) {
      this.delayMs = CEIL_MS;
      this.consecutiveOk = 0;
      return;
    }
    if (statusCode >= 200 && statusCode < 300) {
      this.consecutiveOk++;
      if (this.consecutiveOk >= HALVE_AFTER_OK) {
        this.delayMs = Math.max(FLOOR_MS, Math.floor(this.delayMs / 2));
        this.consecutiveOk = 0;
      }
      return;
    }
    // Other codes: no-op (mirror analog's "healthy resets, anything else is held")
  }

  onBlock(): void {
    this.delayMs = CEIL_MS;
    this.consecutiveOk = 0;
  }

  /** Test-only accessor mirroring `BlockDetector.consecutiveThin` (analog line 67). */
  get consecutiveOkCount(): number {
    return this.consecutiveOk;
  }
}
```

**No timer side effects pattern** (analog has zero `setTimeout`; the rate-limiter is identical - timing belongs in `http.ts`):
- Analog's threat-model comment at line 18 ("bounded patterns only - no nested quantifiers - no ReDoS surface") shows the analog's discipline. The rate-limiter mirrors: bounded integer math, no recursion.
