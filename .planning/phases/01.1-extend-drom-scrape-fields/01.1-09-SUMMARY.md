**1. [Rule 1 - Bug] Fixed puppeteer 24.x screenshot() Uint8Array return type incompatibility**
- **Found during:** Task 1 — first test run
- **Issue:** puppeteer 24.x `page.screenshot()` returns a `Uint8Array` rather than a Node.js `Buffer`. Passing this directly to `PNG.sync.read()` (pngjs) throws `TypeError: data.readUInt32BE is not a function` because pngjs expects a Buffer with the `readUInt32BE` method
- **Fix:** Added `Buffer.isBuffer(data) ? data : Buffer.from(data as Uint8Array)` coercion immediately after the `page.screenshot()` call
- **Files modified:** `server/tests/bmw-pilot-viewer.test.ts`
