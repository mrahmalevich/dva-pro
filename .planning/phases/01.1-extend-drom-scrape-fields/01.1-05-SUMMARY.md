## What Was Built

**Task 1 — TrimRowRef + extractTrimRows:**

New `TrimRowRef` interface added to `parse-generation-page.ts` (exported). Fields: `comp_id`, `url`, `name`, `period_from`, `period_to`, `tier` (union of known Drom tier labels | null), `engine_code`, `frame_code`, `price_new_rub`, `price_used_from_rub`, `engine_cc`, `engine_hp`, `engine_fuel`, `drive`.

`extractTrimRows(html, ctx)` iterates `$('tbody')` per engine group. Within each tbody:
- Collects `engine_code` / `frame_code` from `._13wmddp3 a` links in `._13wmddp0` rows
- Collects used price from "Цена б/у:" span in `._13wmddp3`
- Iterates `tr.y7l57t2` trim rows: extracts comp_id via URL regex, tier from `._1hw1iq10` span, name from `.y7l57t4` cell, period from `._1drdagf0`, new price from `td.y7l57t0` with ₽
- Inherits engine/frame/used-price from the enclosing tbody scope

BMW X5 G05 fixture yields 33 trim rows — well above the 30-row threshold.

**Task 2 — parseComplectationPage (6 field groups):**

`server/scrapers/drom/parse-complectation-page.ts` — 325 LOC, zero `throw` statements, fully fail-soft.

Helper chain: `valueByLabel($, label)` → `numFromLabel` / `intFromLabel` for typed extraction. Key extractor functions:

- `extractDimensions($)`: combined "Габариты кузова (Д x Ш x В), мм" cell split on ` x ` for L/W/H; separate label lookups for wheelbase, clearance, weights; `trunkRange()` helper for "N (M)" format
- `extractComfort($)`: "Число мест", "Число дверей", fuel consumption triplet (city/highway/mixed), tank volume
- `extractTires($)`: "Передние колеса"/"Задние колеса" in detail table; "Передние шины"/"Задние шины" in summary block as fallback
- `extractDrivetrain($, trimRow)`: drive type from `trimRow.drive`; transmission_type from name regex (AT/MT/CVT/AMT/DCT); gear count from trailing digit in "Тип трансмиссии" value; displacement/power/fuel from `trimRow`
- `extractEngine($, trimRow)`: engine_cc, engine_hp, engine_fuel proxied from TrimRowRef
- `extractIdentity(ctx)`: source_url from `ctx.sourceUrl`, name from `ctx.trimRow.name`, brand/model/generation slugs
- `extractPricing(ctx)`: price_new_rub and price_used_from_rub proxied from `ctx.trimRow`

`safeExtract<T>(fn, fallback)` wraps each extractor in try/catch returning fallback on error.

`parseComplectationPage(html, ctx)` wraps `cheerio.load()` in try/catch, calls each `safeExtract`, assembles candidate, calls `ComplectationSchema.safeParse(candidate)` — returns valid record or `allNullComplectation(ctx)` fallback.
