## esc() XSS Audit

All three Complectation leaf use sites in `renderModalBody` are wrapped in the browser's `esc()` helper:
- `esc(c.identity.tier)` — tier string from drom-side context
- `esc(c.identity.name || '?')` — name string from drom-side context
- `esc(c.tires.tires_front)` — tire spec string from drom-side page parse

Accepted criteria: `grep -c "esc(c.identity.tier|esc(c.identity.name|esc(c.tires.tires_front" report-html.ts` returns 3.
