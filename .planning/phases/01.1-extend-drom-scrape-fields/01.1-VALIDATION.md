# Phase 01.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Derived from `01.1-RESEARCH.md` § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 3.2.4 |
| **Config file** | none (vitest default discovery: `server/tests/**/*.test.ts`) |
| **Quick run command** | `pnpm test -- <single-test-file>` |
| **Full suite command** | `pnpm test` |
| **Type check** | `pnpm typecheck:server` |
| **Estimated runtime (full suite)** | ~60 s (108 existing + ~30 new tests; +3–8 s for puppeteer launch on screenshot test) |

---

## Sampling Rate

- **After every task commit:** Run the single test file the task touches (typically <2 s).
- **After every plan wave:** Run `pnpm typecheck:server && pnpm test`. Total <60 s.
- **Before `/gsd-verify-work`:** Full suite green AND a real BMW pilot run (~5–7 h) producing `report.json` with `field_coverage ≥ 0.70` on all six groups. The BMW pilot run is the end-to-end manual gate; everything else is automated.
- **Max feedback latency:** 60 seconds (full suite).
