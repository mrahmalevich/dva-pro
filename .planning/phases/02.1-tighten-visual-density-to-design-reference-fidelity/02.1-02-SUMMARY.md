## Changes Made

### Edit 1 — Hero `<header>` style at line 37 (D-02a + R-6)

**Before:**
```tsx
style={{ position: 'relative', minHeight: '100vh', background: 'var(--ink)', color: '#fff', overflow: 'hidden', paddingTop: 140 }}>
```

**After:**
```tsx
style={{ position: 'relative', minHeight: 640, background: 'var(--ink)', color: '#fff', overflow: 'hidden', paddingTop: 72 }}>
```

- `minHeight: 640` is numeric (px implied) — matches house style (`width: 700` at G-01 blob line 55)
- `640 = 80 × 8` — valid spacing-scale multiple
- `paddingTop: 72` aligns with the new canonical `section { padding: 72px 0 }` from plan 02.1-01

### Edit 2 — Stats grid at line 125 (D-02b + R-8)

**Before:**
```tsx
<div style={{ display: 'grid', gridTemplateColumns: 'repeat(4, 1fr)', gap: 0, marginTop: 96, paddingTop: 32, borderTop: '1px solid var(--line)' }}>
```

**After:**
```tsx
<div style={{ display: 'grid', gridTemplateColumns: 'repeat(4, 1fr)', gap: 0, marginTop: 56, paddingTop: 20, borderTop: '1px solid var(--line)' }}>
```

- `marginTop: 56` = 7×8 — on-scale
- `paddingTop: 20` = 5×4 — on-scale
- Saves ~52 px; prevents stats cramping against Marquee after hero shrinks
