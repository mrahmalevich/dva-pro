    Required label probes (use case-insensitive grep -i):
    1. `Тип гибридной системы` OR `Гибридная система` OR `Тип гибрида` — for `drivetrain.hybrid_type`
    2. `Ёмкость батареи` OR `Объём батареи` OR `Ёмкость аккумулятор` — for `drivetrain.battery_capacity_kwh`
    3. `Запас хода на электротяге` OR `Электрический запас хода` OR `Запас хода (электро` — for `drivetrain.electric_range_km`
    4. `Максимальная скорость` — for `drivetrain.max_speed_kmh`
    5. `Разгон 0` (with any of `100`, `до 100`, `до сотни`) — for `drivetrain.acceleration_0_100_s`
    6. `Передняя подвеска` OR `Тип передней подвески` — for `chassis.suspension_front`

    Verification command (substitute COMP_ID):
    ```bash
    F="server/tests/fixtures/drom/complectation/$COMP_ID.html"
    HITS=0
    grep -ciE 'тип гибридной системы|гибридная система|тип гибрида' "$F" | grep -qvE '^0$' && HITS=$((HITS+1))
    grep -ciE 'ёмкость батареи|объём батареи|ёмкость аккумулятор' "$F" | grep -qvE '^0$' && HITS=$((HITS+1))
    grep -ciE 'запас хода на электро|электрический запас|запас хода \(электро' "$F" | grep -qvE '^0$' && HITS=$((HITS+1))
    grep -ciE 'максимальная скорость' "$F" | grep -qvE '^0$' && HITS=$((HITS+1))
    grep -ciE 'разгон 0' "$F" | grep -qvE '^0$' && HITS=$((HITS+1))
    grep -ciE 'передняя подвеска|тип передней подвески' "$F" | grep -qvE '^0$' && HITS=$((HITS+1))
    echo "Hybrid label hits: $HITS / 6 (need >= 4)"
    [ "$HITS" -ge 4 ] || { echo "FAIL: too few hybrid labels — escalate"; exit 1; }
    ```

    If the check fails, delete the captured fixture and loop back to Task 1 with a note to choose a different trim.
  </action>
